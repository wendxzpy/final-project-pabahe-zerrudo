# User Stories

### Feature: Product Listing
US1: As a user, I want to view categorized local produce cards with unit prices and availability so that I can find affordable farm goods.
US2: As a user, I want to search and filter product listings so that I can quickly see matching items.
US3: As a user, I want to open a product's details so that I can read its description, unit price, and availability before buying.

### Feature: Farmer Profiles
US1: As a user, I want to open a farmer's profile from a product card or product details view so that I can verify the farm source of my product.
US2: As a user, I want to view a farmer's listed products with their prices and availability so that I can order directly from that farmer.

### Feature: Order Summary
US1: As a user, I want to add produce items to my shopping cart so that I can collect items for a single purchase.
US2: As a user, I want to adjust item quantities or remove items in my shopping cart so that my order matches what I need.
US3: As a user, I want to select a delivery option and review an itemized order summary with the total cost so that I can confirm my order with transparent pricing.

### Feature: Order Tracking
US1: As a user, I want to view my order history in My Orders so that I can review my past and current orders.
US2: As a user, I want to select an order to open and track it so that I can check its delivery progress.
US3: As a user, I want to see real-time status updates from confirmation to delivery so that I know when my order will arrive.
